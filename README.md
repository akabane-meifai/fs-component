## FS Editorを使用した作成方法

### インポート
1.**インポート**ボタンをクリックしてインポートダイアログを表示します。
1.**CDN: ソースを選択**で`GitHub`を選択し、`akabane-meifai/fs-component`を入力
1.**CDN上のファイル**で`/`を選択
1.**ローカル保存先**で`/`を選択
1.**パッケージを確認**ボタンをクリックして、この`README.md`が見えたら**インポート**ボタンをクリックしてインポートを開始します。

### ビルド
1.サイドバーの**マクロ**タブをクリックして、マクロタブを表示します。
1.表示されたマクロの**ビルド**にある**実行**ボタンをクリック
1.コンソールが開いて、`ビルド完了`と表示されたら、`/dist/`に成果物（`app.js`,`index.html`）が生成されます。

※FS Editorを再読み込み（リフレッシュ）すると、エディタ上で反映された内容を確認できます。
